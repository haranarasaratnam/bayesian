Linear Quadratic Regulation (LQR)

The next step in the design process is to find the vector of state-feedback control gains, assuming that we have access (i.e., can measure) all four of the state variables. This can be accomplished using the Linear Quadratic Regulator (LQR) method, which generates the "best" gain matrix without explicitly choosing to place the closed-loop poles in particular locations. This type of control technique optimally balances the system error and the control effort based on a cost that the designer specifies, defining the relative importance of minimizing errors and minimizing control effort.

The LQR method involves defining a cost function \( J \) that the controller aims to minimize:

\[ J = \int_0^\infty (x^T Q x + u^T R u) \, dt \]

In this equation:

  • \( x \) is the state vector.
  • \( u \) is the control input.
  • \( Q \) is a positive semi-definite matrix that penalizes the state variables.
  • \( R \) is a positive definite matrix that penalizes the control effort.

The matrices \( Q \) and \( R \) are chosen by the designer to reflect the desired trade-off between state regulation and control effort. Once these matrices are defined, the optimal state-feedback gain matrix \( K \) can be computed using MATLAB's lqr function: 

K = lqr(A, B, Q, R);

The control law is then defined as:

\[ u = -Kx \]

By applying this control law, the system's performance is optimized according to the specified cost function, achieving a balance between minimizing state errors and control effort.

Adding Precompensation

In the previous section, we designed a state-feedback controller using the Linear Quadratic Regulator (LQR) method. However, this controller does not account for steady-state errors in response to constant reference inputs. To eliminate steady-state error, we can introduce a precompensator gain, often denoted as \( N \), which scales the reference input appropriately.

The precompensator gain \( N \) is calculated to ensure that the closed-loop system accurately tracks the reference input \( r \) without steady-state error. The control law with precompensation is given by:

\[ u = -Kx + Nr \]

To determine \( N \), we consider the steady-state behavior of the system. At steady state, the derivative of the state vector \( x \) is zero (\( \dot{x} = 0 \)), leading to:

\[ 0 = Ax_{ss} + Bu_{ss} \]

Substituting the control law into this equation, we get:

\[ 0 = A x_{ss} + B(-K x_{ss} + Nr) \]

Solving for \( x_{ss} \), we have:

\[ x_{ss} = (A - BK)^{-1} B Nr \]

The output at steady state is:

\[ y_{ss} = C x_{ss} \]

To ensure that the output \( y \) matches the reference input \( r \) at steady state, we set \( y_{ss} = r \), leading to:

\[ r = C (A - BK)^{-1} B Nr \]

Solving for \( N \), we obtain:

\[ N = \left[ C (A - BK)^{-1} B \right]^{-1} \]

In MATLAB, the precompensator gain \( N \) can be computed as follows: 

N = inv(C * inv(A - B * K) * B);

By incorporating this precompensator gain into the control law, the closed-loop system will have zero steady-state error in response to constant reference inputs.
