Estimation II: Discrete-Time Kalman Filter

1. Background

The problem we are seeking to solve is the continual estimation of a set of parameters whose values change over time. Updating is achieved by combining a set of observations or measurements \( z(t) \) which contain information about the signal of interest \( x(t) \).

The role of the estimator is to provide an estimate \( \hat{x}(t + \tau) \) at some time \( t + \tau \). If \( \tau > 0 \), we have a prediction filter; if \( \tau < 0 \), a smoothing filter; and if \( \tau = 0 \), the operation is called filtering.

2. Notation

  • \( z_k \): Observation vector at time \( k \)
  • \( Z_k \): The set of all observations up to (and including) time \( k \)
  • \( x_k \): System state vector at time \( k \)
  • \( \hat{x}_{k|i} \): Estimation of \( x \) at time \( k \) based on time \( i \)
  • \( P_k \): Covariance matrix
  • \( F_k \): State transition matrix
  • \( G_k \): Input (control) transition matrix
  • \( H_k \): Output transition matrix
  • \( w_k \): Process noise vector
  • \( v_k \): Measurement noise vector

3. System and Observation Model

The system can be modeled by the state transition equation:

\[ x_{k+1} = F_k x_k + G_k u_k + w_k \]

And the observations can be modeled as:

\[ z_k = H_k x_k + v_k \]

4. Assumptions

  • \( E[w_k w_l^T] = Q_k \) for \( k = l \)
  • \( E[v_k v_l^T] = R_k \) for \( k = l \)
  • \( E[w_k v_l^T] = 0 \) for all \( k, l \)

5. Prediction Step

The predicted state is given by:

\[ \hat{x}_{k+1|k} = F_k \hat{x}_{k|k} + G_k u_k \]

The predicted error covariance is:

\[ P_{k+1|k} = F_k P_{k|k} F_k^T + Q_k \]

6. Update Step

The Kalman Gain is given by:

\[ K_{k+1} = P_{k+1|k} H_{k+1}^T (H_{k+1} P_{k+1|k} H_{k+1}^T + R_{k+1})^{-1} \]

The updated state estimate is:

\[ \hat{x}_{k+1|k+1} = \hat{x}_{k+1|k} + K_{k+1} (z_{k+1} - H_{k+1} \hat{x}_{k+1|k}) \]

The updated error covariance is:

\[ P_{k+1|k+1} = (I - K_{k+1} H_{k+1}) P_{k+1|k} \]

7. Innovation

The innovation is defined as:

\[ \nu_{k+1} = z_{k+1} - H_{k+1} \hat{x}_{k+1|k} \]

And its covariance is:

\[ S_{k+1} = H_{k+1} P_{k+1|k} H_{k+1}^T + R_{k+1} \]

8. Example

Consider a vehicle tracking problem where a vehicle is constrained to move in a straight line with constant velocity. The system state equations are:

\[ x_{k+1} = F_k x_k + w_k \]

\[ z_k = H_k x_k + v_k \]

9. Conclusion

The Kalman filter offers an optimal recursive estimation framework for linear Gaussian dynamic systems.
